# Mental Health & Workplace Analytics

Exploratory analysis of how work pressure relates to job satisfaction
in a Kaggle dataset of working professionals.

Tools: R, ggplot2, dplyr, readr
Dataset: [Depression Professional Dataset on Kaggle](https://www.kaggle.com/datasets/ikynahidwin/depression-professional-dataset) (CC0 Public Domain), 2,054 records of working adults aged 18-60.

## Files
- `Final group Project.Rmd`: analysis code
- `Final-group-Project.html`: knitted report
- `data/`: dataset

## Key finding
Average job satisfaction ranged only from 2.97 to 3.07 across work
pressure levels, a very small difference. No significance test was run.
